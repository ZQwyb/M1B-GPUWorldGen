M1B-GPUWorldGen

在手机的 GPU 上跑 Minecraft Java 版的世界生成噪声

MC 26.3 Fabric 0.20.1 Java 25 GLES 3.2 / MobileGlues License MIT

它做什么

用 Java FFM 在游戏已有的 EGL 上下文里直接绑定 GLES，用 fragment shader + double-double 模拟双精度，精确复刻 Minecraft 的 PerlinNoise， 把 3D 密度噪声从 GPU 取回来供世界生成使用。误差 < 1e-6。

不替换世界生成器、不改存档、不打包任何 Minecraft 代码——只是一个噪声加速适配层， 失效时自动退回原版 CPU 路径。

坦白说：在 MobileGlues 的「FBO + 回读」模型下，逐点 GPU 计算约 61 ns/值 + 每次 draw 0.9 ms 固定开销，而同一台手机 CPU 只要 67 ns/值。所以逐点接管命中率长期偏低—— 真正能赢的是 MC 26.3 的 addToVolume 批量入口，正在验证。
